# Store assets

Generated by `python3 tools/generate_store_assets.py` from committed sources —
the leaf mark in `assets/icon.svg` and the runtime captures in `previews/`.
Regenerate rather than editing by hand; the outputs are deterministic.

```
icon_512.png                    Play app icon, 512x512, no alpha
feature_graphic_1024x500.png    Play feature graphic
tv_banner_1280x720.png          Android TV / leanback banner
screenshots/phone/              4 unretouched 1920x1080 runtime captures
listing/short_description.txt   <= 80 chars
listing/full_description.txt    <= 4000 chars
listing/whatsnew/whatsnew-en-US <= 500 chars, uploaded with every CI release
```

The launcher icons the app itself ships (`assets/icon_192.png` and the two
432x432 adaptive layers) come from the same generator and are referenced by the
`Android Play` export preset.

Screenshots are real frames with no added marketing overlay. They do not show
the ad banner, which is normal for store listings.

See [`docs/play-store.md`](../docs/play-store.md) for the full release process.
